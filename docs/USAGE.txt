币安永续行情任务栏小条
========================

默认显示：
- BTCUSDT 比特币永续
- NVDAUSDT 英伟达永续
- SNDKUSDT 闪迪永续

操作：
1. 迷你 K 线在现价左侧。
2. 右键勾选“固定位置”可锁定位置；取消后可拖动。
3. 右键小条打开菜单。
4. 托盘图标双击显示/隐藏。
5. “开机启动”可设置登录 Windows 后自动运行。

刷新：
- 现价默认约每 250ms 从 Binance 行情接口刷新一次。
- 24h 涨跌幅约每秒更新。
- K 线默认显示最近 14 根 1 分钟 K 线。

配置文件：
%LOCALAPPDATA%\BinanceTaskbar\settings.json

数据全部来自 Binance Futures，不需要 API Key。
